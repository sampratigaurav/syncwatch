## 2024-05-24 - [Input Validation and Length Restrictions]
**Vulnerability:** Missing data type and length validation on user input data in Express routes (`server/src/routes/users.ts` and `server/src/routes/friends.ts`).
**Learning:** By default, Firebase Admin SDK (Firestore) and Express do not validate the type or limit the size of data pulled directly from `req.body` into database queries. Attackers could theoretically pass in massive payloads causing a DoS by exhausting Firestore document size limits, or send object literals that break string manipulation logic.
**Prevention:** Always explicitly validate that expected string inputs are indeed strings (`typeof field === 'string'`) and enforce a maximum length appropriate for the field context before utilizing the data or persisting it to the database.
