## 2026-09-29 - [Missing Firebase Admin SDK Input Validation]
**Vulnerability:** The Express routes using the Firebase Admin SDK (`/api/users/initialize` and `/api/users/profile`) directly passed `req.body` properties (`displayName`, `photoURL`, `email`, `avatarUrl`) to Firestore operations without verifying data types or maximum lengths.
**Learning:** Firestore via the Firebase Admin SDK does not perform automatic schema validation like traditional relational databases. Passing unvalidated user input directly into `userRef.set()` allows attackers to overwrite document fields with unexpected data types (e.g., arrays or objects), potentially causing NoSQL injection, type-confusion bugs, or DoS attacks via excessively large payloads.
**Prevention:** Always explicitly validate `typeof req.body.field === 'string'` and enforce maximum length limits (e.g., 50 characters for names, 2000 for URLs) in Express routes before interacting with the Firebase Admin SDK.
